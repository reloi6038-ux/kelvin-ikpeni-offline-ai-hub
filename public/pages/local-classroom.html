Local Classroom Mode

One device serves as the learning hotspot. Nearby students join without individual data plans. Perfect for classrooms, study groups, or community learning centers.

How it works

🖥

Teacher's Device

Runs the Kelvin Hub server locally and shares its Wi-Fi hotspot.

📡

Local Network

Students connect to the hotspot. No internet needed for local access.

📱

Student Devices

Open the classroom URL. Download packs. Learn. Sync when back online.

Ready to try it?

Local Classroom Mode requires a small local-network setup. In a real deployment:

  1. Start the Kelvin Hub server on the teacher's laptop.
  2. Enable the laptop's Wi-Fi hotspot (Windows: Mobile hotspot; Linux: create_ap; Mac: Sharing → Internet Sharing).
  3. Note the laptop's local IP address (e.g. 192.168.137.1).
  4. Students connect to the hotspot and open http://192.168.137.1:3000 in their browser.
  5. They can download packs, take quizzes, and use the AI tutor.
  6. When they reconnect to the internet, everything syncs back to the main server.

This prototype can demonstrate the concept on a single machine. Full multi-device classroom mode requires the server to be reachable on the local network — the codebase is ready, just needs a network configuration step.

What works today

Even without the local hotspot setup, students can:

  • ✅ Download learning packs at home
  • ✅ Use everything offline on the bus, at school, in the village
  • ✅ Sync quiz attempts when they next connect
  • ✅ Share a device with siblings — each has their own progress
